# Template placeholder icon

file here with your game's icon before release, keeping the sizes:

| File | Size | Used for |
|---|---|---|
| `icon.png` (project root) | 256 | Project icon, PC window |
| `icon_main_192.png` | 192 | Android launcher icon (older launchers) |
| `icon_foreground_432.png` | 432 | Adaptive icon foreground; keep artwork inside the centred 264 px circle |
| `icon_background_432.png` | 432 | Adaptive icon background |
| `icon_monochrome_432.png` | 432 | Themed (monochrome) icon on Android 13+ |
| `icon_splash_512.png` | 512 | Android 12+ launch splash (`splash_screen/icon`) |
